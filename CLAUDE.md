# Instructions

This repository is a skills library for LLMs. Read [AGENTS.md](AGENTS.md) first and follow it.

## docs

`docs/` is a wiki maintained by an LLM. Page format, which page to update, and the
`/docs-sync` workflow all live in [`docs/CLAUDE.md`](docs/CLAUDE.md).
Start at [`docs/index.md`](docs/index.md). `docs/SKILL_STANDARD.md` is the skill
standard itself, not a wiki page.
